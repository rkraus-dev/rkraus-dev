# Hey there! 👋
I'm **Robert**, an aspiring **.NET Developer** based in Bavaria, Germany.

Trained as a **Software Developer (Fachinformatiker Anwendungsentwicklung)**, 
I spent 8 years in 2nd Level IT Support — but I never stopped building things.

My path back to development started organically — during my time in IT Support, 
I began automating repetitive workflows using **AutoIt**, improving and 
accelerating processes along the way. That spark of "I want to build more 
than this" never left. So I made it official: back to development, this time 
with a clear focus on the **Microsoft .NET ecosystem**.

My background gives me something most junior developers don't have: I understand 
systems, I know how to read documentation, and I stay calm when things break. 
Now I apply that same mindset to writing clean, maintainable C# code.

This GitHub profile is my technical lab — every repo here is a step on that path.

For a more personal look at my background and goals, visit **[rkraus.dev](https://rkraus.dev)**.
